# kuhai 的个人网站

更新：2026-10-12

## 资料归档方法

研究结论按日期保存，必须记录来源、采用理由、冲突和未决问题；修改方向写入决策记录。正式采用的规则汇入对应设计文档，历史资料保留。主舰资料放在本目录，避免与上游用于参考代码检出的根目录 `research/` 混淆。

文本、图表源文件、资产清单和体积适宜的网页资产进入 Git。高精度建模母版和大型材质工程在明确托管容量后使用 Git LFS 或独立资产存储，仓库记录版本、校验值与获取方式。未取得使用条件的参考作品只保存出处和研究笔记。

Shirone 的原始许可证与作者信息继续保留；每份美术资产单独记录使用条件。
