# 舰桥侧舷结构样板的依据

本轮解决用户提出的“乐高拼接感”：原左舷支撑是一整块连续实心体，缺少外层装甲、设备承架和内部边界的层次。沿用已选舰型，在该区域设计两个非气密设备凹舱；空间、设备种类、管线路径和尺寸属于网站原创补全。

## 原创部件分工

| 区域或部件 | 设计用途 | 几何关系 |
| --- | --- | --- |
| 左舷支撑 | 舰桥基座的连续受力路径 | 保留上下边框和中间肋，两个开口使用可编辑布尔生成 |
| 前设备凹舱 | 三组可更换电子设备 | 模块、承架、后安装臂、线束和汇接点分开制作 |
| 后设备凹舱 | 虚构的执行器／流体设备 | 垂直组件、分体卡箍、上方总管、下方回路与后安装臂对应 |
| 凹舱后壁 | 人员舱之外的独立边界 | 与前方装甲之间留出真实纵深，不作为暴露在真空中的室内通风口 |
| 外缘 | 维护与保护 | 密封边、压条、可拆护板、固定座和遮光工作灯集中在功能位置 |

本轮只做左舷样板，另一侧保留前版以供后续方向确认。机械布局和尺度仍需随着官方参考与整舰空间规划调整；这些视觉连接不等于完成承载、热控或压力工程验证。
