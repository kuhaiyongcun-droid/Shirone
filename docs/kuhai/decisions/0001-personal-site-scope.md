# 0001 kuhai 个人网站的项目范围

日期：2026-10-10

## 已确认

- 产品名称是 kuhai 的个人网站；Shirone 是档案室博客模块的基础，不是整个个人网站的名称。
- 现有仓库作为继续维护代码、设计研究与资产记录的基础。
- 休伯利安号式战舰是整个网站的主页面，重点投入模型、质感、光影与周边星体。
- 主动旋转、舰体局部高亮与剖视方向保留；悬停不得让整舰或相机晃动。
- 舱室独立，切换先返回主舰；博客继续保留 Shirone 的阅读布局。

## 工程建议

先整理项目入口与文档，再在同一 Astro 工程中引入主舰模块。博客分离与路由迁移分阶段验证。采用高精度制作母版与分档网页资源，给性能有限的访客保留主要交互和静态入口。

## 尚未确认或完成

- GitHub 仓库重命名为 kuhai-site。
- 全站正式舱室名称、完整清单与所有功能。
- 最终主舰资产、现实硬件上的性能和网页资源预算。
- 将现有博客路由实际迁移到 /blog/。
- 本批准备不代表代码重构、GitHub 同步或网站部署已完成。

## 影响

网站品牌、博客技术来源与仓库标识分别维护。上游 Shirone 的使用说明、署名与许可证保留。研究过程进入 docs/kuhai，以来源、结论、设计决策与测量结果组织。
