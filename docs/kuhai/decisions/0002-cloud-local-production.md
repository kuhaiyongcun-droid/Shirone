# 决策 0002：云端与本地建模分工

日期：2026-10-10。依据：用户本轮明确补充。状态：已采用。

## 制作职责

云端自主推进参考整理、比例与舱区规划、程序化草模、图片生成、交互样板和低分辨率预览。每次会话先清点实际工具和资源，不从其他会话推断 Blender 或 GPU 可用。

家中 RTX 3060 Ti 是后续复杂建模、材质灯光、高清渲染与批量烘焙的候选制作资源。只有用户明确说家里的电脑已连接，才能核对目标机器、授权、软件、驱动和可用显存，之后先做小样。当前分工不是访问授权，不能在其他机器启动重负载。

先依据实际工作量记录耗时、内存/显存、失败与资源余量，再决定转交哪项任务。不能只因为模型复杂就认定必须本地，也不能因云端慢而降低最终主舰的美术目标。没有默认购买素材、服务或租用付费 GPU 的授权。

## 资产交接约定

每个可迁移版本包括可编辑 `.blend`、所需贴图、生成/导出脚本、依赖与版本、渲染设置、启动步骤、预期产物、检查记录与校验值。资源采用相对路径或打包，不依赖临时云端目录。脚本和过程文档进入本仓库，源场景通过持久任务包或将来确定的资产存储交付。

高精度制作源文件与网页模型分别管理。网页几何、纹理、绘制批次、分辨率、加载量和交互性能按访客设备实测优化。制作时使用 3060 Ti 不意味着访客也需要它。

## 设计职责保持

主舰设计工作维护全站主入口、外观、星体环境、舱区剖视和进入/返回契约。博客设计工作维护 Shirone 档案室的内部布局与阅读体验；两边共享必要的美术标准，不相互覆盖。

悬停不移动相机或整舰；主动拖动才旋转。舱室切换先返回主舰。高质量目标、少量首页控件、档案室保留 Shirone 布局等既有要求继续有效。

## 当前执行结果

本会话原始环境无 Blender 可执行文件、无 NVIDIA 设备或 `nvidia-smi`；容器限制为 8 核 CPU、8 GiB 内存。已在独立虚拟环境安装 Blender Foundation 的 `bpy 4.5.14`，用 Cycles CPU 完成草模和预览。当前样本未形成必须切换本地的算力瓶颈；不据此推断最终高精度场景成本。
