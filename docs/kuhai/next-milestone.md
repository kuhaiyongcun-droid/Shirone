# 主舰设计下一阶段

目标：先确定可信的舰体外观、内部比例与共同美术标准，再把它们制作成可在网页运行的模型。当前旋转、舱区高亮与剖视交互方向继续沿用。

## 按顺序交付

| 阶段 | 产物 | 确认重点 |
| --- | --- | --- |
| 1 参考依据 | 官方与创作者来源清单、舰首/侧面/尾部/腹部参考板、冲突与缺失区域记录 | 选择统一的休伯利安号主参考，区分通用战列巡航舰和目标舰 |
| 2 结构与比例 | 多视角舰体结构草模、甲板与档案室区域示意 | 舰型辨识度、舱区容积、外壳厚度与人体尺度 |
| 3 材质与光影 | 一段舰体装甲、引擎、一个档案室及星体的同场景样板 | 金属与漆面、磨损逻辑、灯光层次、星体受光方向 |
| 4 可运行样板 | 整舰旋转、档案室高亮剖视、进入与返回、画质分档 | 桌面与触屏交互、低动态偏好、核显与手机性能 |
| 5 网站接入 | 主舰入口与 Shirone 档案室的路由和资源边界 | 旧链接、语言切换、直接访问博客、释放 3D 资源 |

每阶段保留可审阅产物与来源，已确认的部分形成后续制作基准。存在矛盾时先解决造型和比例，再增加表面细节。

## 第一阶段的研究问题

- 优先整理《自由之翼》中已展示的休伯利安号，再比较概念图、过场画面和二创模型的差异。
- 确认舰首、两侧大体量结构、舰桥与引擎群在不同机位下的对应关系。
- 区分实机单位模型、宣传画面与人物尺度场景，避免直接把单张图的透视当尺寸依据。
- 腹部、背部和完整内部结构没有充分证据的部分，明确列为网站创作补全。
- 二创资料先用来研究结构和制作方法；实际采用的模型或纹理另行核对文件与使用条件。

## 资源与范围

集中打磨整舰外观、星体环境与一个档案室。先形成连贯的内部空间规划，暂不制作所有隐藏房间。高精度母版和网页导出分别维护；画质预算在样板完成后根据实测调整。

研究过程归档到本目录下的 references，采用素材进入 assets/registry.csv，改变范围或技术方向时新增 decisions 记录。博客内部布局由博客设计工作继续维护，主舰工作负责共同美术与入口契约。
