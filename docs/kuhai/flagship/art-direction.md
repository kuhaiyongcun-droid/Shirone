# 主舰美术方向

主舰是 kuhai 个人网站的核心作品，制作投入以高质量模型、材质、光影和太空环境为重点。最终资产制作需要多轮美术审查，当前交互草模只验证交互方向。

## 制作重点

| 层次 | 设计要求 |
| --- | --- |
| 舰体轮廓 | 选定一致的休伯利安号主参考；舰首、舰桥、侧翼、引擎、腹部和背面均经多视角检查 |
| 结构 | 装甲、承重、维护开口、设备和管线能够解释用途；内部舱区与舰体体积对应 |
| 材质 | 金属与漆面区分，统一纹理尺度、粗糙度和旧化规则；边缘和使用位置有自然磨损 |
| 灯光 | 一致的恒星方向、舰体明暗层次、受控的引擎与工作灯辉光；避免灯光淹没金属质感 |
| 星体 | 与舰体共用主光方向，明确行星尺度、距离、明暗分界和有无大气层；只渲染镜头需要的细节 |
| 环境 | 星空、薄尘、镜头曝光与色调共同服务舰体主体；动态强度保持克制 |
| 内部剖视 | 高亮贴合实际舱区，显示有厚度的外壳、舱壁和设备；避免透明外壳造成重叠混乱 |

## 制作与网页版本

保留高精度建模母版，用于雕刻、烘焙与高质量静帧。网页使用经过拓扑整理、UV、材质归并与压缩的导出模型，并按镜头距离与设备选择细节级别。小型铆钉、装甲凹槽等按可见尺度决定采用几何还是法线贴图。

在网页版本中优先投入可被访客看到的轮廓、关键结构、材质反应与光影。整舰外观与可剖视舱区需要连贯，隐藏且不会进入的房间先保留结构规划。

## 交互约束

- 访客主动拖动才旋转；悬停不晃动舰船、不改变相机。
- 选区反馈发生在舰体区域，点击后允许受控靠近与进入；返回保留可理解的空间位置。
- 手机触控采用先选中再进入的方式，避免拖动结束触发进入。
- 不把大量控制面板、跨舱卡片或性能调试信息放到首页。
- 低动态偏好、性能不足或 WebGL 不可用时，仍能从主舰海报进入档案室。

## 首轮美术审查

先完成一组固定机位：前上方、后方引擎、腹部、档案室剖视和窄屏构图。检查轮廓辨识度、人体比例、舰体和内部空间对应、金属粗糙度、灯光层次与星体受光。各项确认后再扩展舱室和细节。

图像生成适合探索构图、气氛和纹理候选；正式可旋转资产仍需完成一致的三维结构、网格、UV、材质和性能处理。
