# 局部装甲与检修结构 02

日期：2026-10-12。基于 form-study-03 的制作样本；未替换既有网页模型、独立审阅站点或博客。

本轮覆盖舰首上装甲、两侧前肩根部及档案室可移除顶盖。新增 47 片贴合板件、检修盖、锁扣、格栅和项目文字标记。材质区分涂漆与金属接触面，用少量维护批次差异保留大面积安静漆面；具体结构属于网站设计推演。

| 检查 | 实际结果 |
| --- | --- |
| 原始输入 | form-study-03 校验值保持不变 |
| 舱内及环境 | 档案室指纹、原灯光、星体、既有后部细节与原机位约定不变 |
| 新增结构 | 71 个网格、11,988 个求值三角形，另有 1 个可编辑文字对象；网格闭合、正体积、没有进入档案室占用预留区 |
| 剖视归属 | 新屋顶细节属于 ARCHIVE_SHELL 子集合；关闭/拆开两张同机位图已查看 |
| 局部预览 | 当前 4 张、基线 3 张、剖视 1 张，960×600 / 32 采样，CPU 6 线程 |
| 耗时/内存 | 各帧 11.589–17.415 秒，进程峰值 RSS 最高 1,200.79 MiB |
| 网页材质小样 | 实际 4 × 3.2 × 0.2 m 检修盖，147,928 字节 / 108 三角形，3 张内嵌 1024² 贴图 |
| 烘焙与回读 | 3 通道约 3.04 秒；源材质、烘焙材质、实际 GLB 回读均完成 512² 对照 |
| glTF 检查 | Validator 0 错误 / 0 警告 / 0 提示 |

检修盖 GLB 不包含独立锁扣/螺栓，也不是整舰网页资产。R 通道为常数 1，未烘焙 AO；未做真实浏览器和访客设备帧率测量。源材质与烘焙图的全图平均绝对像素差约 0.103/255；烘焙与 GLB 回读约 0.000038/255，仅说明这个受控小样接近，不代表所有光照视角一致。
