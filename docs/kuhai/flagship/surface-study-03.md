# 远近景层次与装甲分区 03

日期：2026-10-12。输入为已恢复并核对 SHA256 的 surface-study-02。仍属于可编辑源模型制作阶段，未发布新网页版本。

本轮将规则小格调整为舰首纵向板、前肩大分区和档案室连续维护带；减少重复分缝，同时保留全部近景硬件。旧板件留在隐藏比较集合，可用同一相机直接切换前后状态。

| 项目 | 结果 |
| --- | --- |
| 局部板件数量 | 47 → 23：舰首 4，前肩各 5，顶盖 9 |
| 局部板件求值三角形 | 9,268 → 4,372；仅指这批板件 |
| 本轮及上一轮局部新增的活动网格三角形 | 11,988 → 7,092，不计字体与隐藏对照，不是整舰统计 |
| 接缝 | 改为按面内距离内缩，名义同平面缝宽 0.20 m |
| 原有数据 | 原网格、对象变换、舱室指纹、原灯光与星体约定保持不变 |
| 剖视 | 新旧顶盖都归 ARCHIVE_SHELL；当前关闭/打开帧已查看 |
| 几何 | 新板件闭合、正体积，没有侵入原档案室占用预留区 |

小尺寸对照仅为单个静态构图，不能代替浏览器帧率、移动端布局或 LOD 动态切换测试。投影尺度与解释详见 [实测记录](../references/2026-10-12-surface-scale-03.md)。本轮没有生成新的整舰 GLB 或再次进行 GitHub 模型二进制上传。

任务包包含 `.blend`、固定输入、资源、脚本、依赖、原始帧与检查记录；说明见 [SURFACE_LAYOUT.md](../../../tools/flagship/SURFACE_LAYOUT.md)。交付校验值维护于 [GitHub 交付记录](https://github.com/kuhaiyongcun-droid/Shirone/blob/main/docs/kuhai/assets/surface-study-03-delivery.json)。
