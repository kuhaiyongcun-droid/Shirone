# 舰桥左舷结构样板 03

日期：2026-10-12。对应 [开发计划](development-plan.md) 的局部设计与结构深化。该样板是接近成品质感阶段的结构初稿；材质细化和整舰扩展继续推进，不能视为最终美术验收。

## 本轮变化

在 home-look-01 上，将左舷舰桥的大块实心支撑改为两个实际内凹设备区域，保留连续承力边框和分隔肋，补充电子模块、执行器式组件、安装臂、总管、回路、可拆护板、压条和工作灯。173 个新对象包含替换支撑及其设备；原支撑留在隐藏对照集合，原始几何、材质节点、档案室和照明检查保持一致。

侧舷仍是本项目的原创解释，来源和功能分工见 [参考记录](../references/2026-10-12-side-structure-03.md)。没有采用新第三方模型、购买素材或启动本地 GPU。

## 对照与网页

前后对照使用相同机位、960×600、32 samples 和中性照明；另保留原首页气氛光、反向观察及整舰场景。图片是实际模型的 CPU 渲染，没有使用生成图片替换结构。

网页主舰 169867 三角面、40 个材质批次、1415256 字节；比前版增加 128608 字节。档案室 GLB 的 SHA-256 与前版一致。网页仍为无全舰贴图烘焙的轻量 PBR，不能把本轮结构更新描述成已完成最终材质。

私有预览保留 [整舰入口](https://kuhai-flagship-review.kuhaiyongcun.chatgpt.site)，并提供 [舰桥局部初始视角](https://kuhai-flagship-review.kuhaiyongcun.chatgpt.site/?view=bridge)。局部视角改变初始观察中心与缩放范围，操作、舱区悬停与进入返回仍沿用现有规则。普通入口继续显示整舰。

## 验证与资源

源模型检查覆盖原对象与材质保留、档案室、灯光、资源可迁移、新网格封闭体积及隐藏前版。实际 Draco 解码、法线、容器和 8 项已有资产／交互测试通过；1440×900 与 390×844 检查新增区域的 20544 个解码顶点均在局部初始视图内，原舱区的可见、遮挡与拾取检查通过。

中性光三张 CPU 样片约 18～26 秒，峰值进程内存约 1275 MiB；这个量级仍可在云端制作。实际浏览器 WebGL 画面、触控事件和设备 FPS 尚未验收。GLB 回读渲染仅检查导出后的几何表现，不替代浏览器测试。

可编辑源、前版输入、贴图、生成／导出／检查脚本、相机设置和运行说明保存在版本化任务包；源码与研究同步 GitHub。操作见 [SIDE_STUDY.md](../../../tools/flagship/SIDE_STUDY.md)。下一轮优先完善设备外壳、装甲接缝、表面材质与细节尺度，依据这块样板继续修正，暂不批量铺满全舰。
