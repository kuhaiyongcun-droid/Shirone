# 舰桥侧后结构与漆面样板 02

日期：2026-10-12。源版本：bridge-study-01。制作说明见 [BRIDGE_FINISH.md](../../../tools/flagship/BRIDGE_FINISH.md)，参考边界见 [本轮记录](../references/2026-10-12-bridge-finish-02.md)。

## 本轮结果

舰脊两侧增加六片沿既有真实斜面布置的装甲、两组检修盖和后侧设备护罩。每组检修盖带紧固件、起吊接点与简短标记。共新增 52 个对象、10,736 个倒角后评估三角形。大面仍保持简洁，近景细节没有扩散到整舰。

漆面样板区分非金属漆层、底漆与露出的合金，以局部米制坐标控制不规则边缘磨损、粗糙度变化和微凹凸。保留程序化节点，并对实际左舷检修盖本体展开 UV、烘焙贴图和导出 GLB；独立螺栓等不包含在这个材质试片内。

| 产物 | 实测 |

## 验证

- 原对象记录、档案室数据和环境约定与输入一致；未修改博客、已发布页面或现有交互。
- 新网格有限、闭合、正体积，包围盒未侵入受保护的档案室区域。此检查不等同全部机械结构、碰撞或强度验证。
- 前后对照用同一场景和机位，仅隐藏新增集合；预览使用受光侧，材质单独使用中性灯光比较。渲染图只缩放排版。
- 烘焙使用三角化复制网格，GLB 包含 UV 和切线；检查粗糙度、金属度、贴图内嵌及真实导入。原源文件校验值不变。
- 迁移包从另一目录实际打开整舰和独立材质样板，检查相对路径、打包资源并重新渲染。具体记录随任务包保存。

本轮没有最终整舰网页资产、浏览器交互验收或访客 GPU 要求结论。云端小样仍可完成，未访问家中电脑。

## 交付和后续

模型、贴图和预览作为版本化任务包保存，仓库维护脚本、研究与 [交付清单](../assets/bridge-study-02-delivery.json)。最终高质量目标保持不变，当前板件、紧固件尺度和漆面仍是样例，需要结合整舰远近景继续调整。后续将逐步检查舰尾连接、重点表面与照明层次，确定后再扩展全舰贴图。
