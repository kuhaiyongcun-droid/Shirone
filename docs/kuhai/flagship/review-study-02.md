# 主舰旋转审阅 02

日期：2026-10-12。[打开私有试用页](https://kuhai-flagship-review.kuhaiyongcun.chatgpt.site)。用户要求一个可以简单旋转观看当前效果的版本，因此在原独立审阅页更新资源与构图，继续保持仅所有者访问。

## 当前体验

左键拖动或单指拖动旋转，滚轮或双指缩放，右上角设置可复位视角。没有自动旋转、惯性或鼠标跟随。已有档案室的局部悬停剖视、进入与返回继续保留；悬停仅影响可见性，不改变镜头或舰体变换。

制作输入更新为 home-look-01，包含装甲分区 03、舰桥 01/02 与推进段 01。导出递归读取可见集合，跳过隐藏历史几何，并读取 HOME01 的对象级材质覆盖。31 个舰体材质批次、159603 三角面，模型 1286648 字节；内部单独按需加载，9 批次、10107 三角面、132040 字节。使用本地 Three.js 与 Draco，无 CDN 依赖。

画面采用轻量 PBR、AgX 和新的共享恒星方向，背景星球按制作源角尺度压缩距离。初始观察方向沿用首页样片，按画幅与包围盒求取相机距离，给上下界面留出空间。网页材质未烘焙全部磨损与粗糙度，光照也没有匹配离线 Cycles 的全部反射和发光效果；不能把实时预览当作最终渲染质量。
